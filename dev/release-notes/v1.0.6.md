# SpotifyTrackHonorific v1.0.6

Stable release promoted from the tested v1.0.6-dev.1 build.

## Highlights

- Added one optional global setting: `Hide Spotify title during combat`.
- Entering combat clears only SpotifyTrackHonorific's Honorific title.
- Spotify polling continues normally while the title is hidden.
- Leaving combat restores the cached current title immediately instead of waiting for the next Spotify API poll.
- Combat auto-hide is global and intentionally not stored inside title profiles.
- Portable settings format advances to v2 and includes the combat auto-hide preference.
- Existing v1.0.5 format-v1 portable exports remain import-compatible and leave the new preference unchanged.
- Configuration schema advances from v10 to v11 with combat auto-hide disabled by default on migration.
- Existing Spotify polling, rate-limit handling, cooldown behavior, profiles, filtering, local-file support, and cycle rendering remain unchanged.
