# SpotifyTrackHonorific v1.0.9

Stable release promoted from the tested v1.0.9-dev1 build.

## Highlights

- Added a Title-tab format builder.
- Added clickable insert buttons for Artist, Artists, Track, Album, Duration, Elapsed, Remaining, Local, and Paused.
- Variable buttons are backed by `TitleTemplateFormatter.SupportedVariables`.
- Added Copy format and Reset format to default.
- Added a cycle builder with seconds per stage, pipe-separated stages, generated `{cycle:...}` preview, and Append cycle.
- Added warnings for missing cycle closing braces, invalid/non-positive seconds, missing stages, and unsupported nested cycle blocks.
- Live preview updates immediately after builder changes.
- Multiple cycle blocks were tested and continue to work independently.
- Existing custom title format persisted across a dev-plugin reload.
- No configuration-schema migration is required.
- `TitleTemplateFormatter.cs` and `ContentFilterMatcher.cs` are unchanged.
- Spotify polling/recovery, Honorific rendering, profiles, portable settings, filtering, and appearance behavior are unchanged.
