# SpotifyTrackHonorific v1.0.8

Stable release promoted from the tested v1.0.8-dev3 build.

## Highlights

- Added scoped quick-add controls for custom blacklist entries:
  - All fields
  - Artist
  - Track
  - Album
- Quick-add prevents duplicate custom rules regardless of capitalization.
- Added custom-entry search/filtering.
- Added per-entry Remove buttons.
- Added Clean + sort to trim, deduplicate, and alphabetize custom entries.
- Added confirmed Clear custom entries.
- Retained the raw multiline editor for bulk paste/edit workflows.
- Improved the matcher tester with All fields / Artist only / Track only / Album only modes.
- Added a warning when a scoped custom term overlaps an active built-in triggerword.
- Built-in triggerwords remain intentionally all-fields.
- ContentFilterMatcher.cs and the underlying matching algorithm remain unchanged.
- No configuration-schema migration is required.
- Spotify polling/recovery, Honorific rendering, saved profiles, portable settings, combat auto-hide, and diagnostics remain unchanged.
