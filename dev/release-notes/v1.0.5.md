# SpotifyTrackHonorific v1.0.5

Stable release promoted from the tested v1.0.5-dev.1 build.

## Highlights

- Up to five named saved profiles for title, playback, appearance and filter settings.
- Profile overwrite, load, delete and persistence.
- Enhanced live title preview.
- Portable JSON settings export/import through the clipboard.
- Spotify credentials/authentication are intentionally excluded from portable exports.
- Safe malformed-JSON rejection without altering the current configuration.
- Configuration schema v10 migration from v1.0.4.
- Pause/resume detection improved: paused playback is checked about every 15 seconds, while truly idle playback remains about every 60 seconds.
- Existing content filtering, cycle rendering, rate-limit handling and Spotify cooldown behavior preserved.

## Validation performed

- Existing v1.0.4 settings migrated successfully.
- Normal Spotify playback and local files passed.
- Pause/resume passed without manual retry.
- Profiles save/load/overwrite/delete/persistence passed.
- Portable export/import passed with Spotify authorization preserved.
- Malformed JSON import was rejected cleanly and left existing settings unchanged.
- Filter/profile interaction and cycle behavior passed.
- 15+ hours of continuous Spotify playback observed without a rate-limit event before release promotion.
